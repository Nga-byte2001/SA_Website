## 4. JavaScript — `initHeroScroll()` in `assets/js/odyssey-ui.js`
ES5 style matching the file. Arms only on ≥901px, motion allowed, WAAPI present. One passive scroll listener + `requestAnimationFrame`; per tick one `getBoundingClientRect()` read → normalized progress → sets `currentTime` on three paused WAAPI animations (art / teal overlay / content). Transform + opacity only, no layout thrashing. Phases: banner hold to 35% → art moves up + scales 1→1.06 while teal fades in (35–70%) → content group reveals from `translateY(48px)`/opacity 0 (50–85%) → readable hold with artwork mostly out of view (no duplicate ODYSSEY) → natural release into "The Meaning of Odyssey". Uses `--odyssey-ease-out`/`--odyssey-ease-in-out`. Content group is `visibility: hidden` until the reveal band so the invisible CTA is never focusable. Resize/orientation rebuild geometry; `pageshow` handles restored scroll; crossing 901px disarms to static.
